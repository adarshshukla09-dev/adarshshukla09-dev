## 🚀 Featured Project

### 🧠 Production-Grade Enterprise RAG Knowledge Base

An AI-powered knowledge retrieval system designed to answer questions
over dense technical documentation.

**Tech Stack**

`Next.js` `AI SDK` `Gemini` `LangChain` `Qdrant` `OpenAI`
`Vector Databases` `Docker`

#### Key Engineering Highlights

- Architected an end-to-end Retrieval-Augmented Generation (RAG) platform
  for querying technical documentation.
- Implemented a hybrid retrieval system combining dense vector embeddings
  in Qdrant with sparse keyword retrieval.
- Improved chunk recall by **25%** through hybrid search.
- Built an evaluation pipeline to measure document question-answering
  performance.
- Achieved approximately **97% accuracy** in the reported document
  evaluation setup.
- Explored local embedding models for the retrieval pipeline.

#### Core Concepts

- Document ingestion and processing
- Embedding generation
- Vector indexing and retrieval
- Hybrid search
- Context construction
- LLM-powered answer generation
- Retrieval evaluation

> The reported accuracy reflects the project's evaluation setup and
> should be interpreted in the context of its dataset and evaluation method.
